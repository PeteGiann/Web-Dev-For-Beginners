### Penpot - Design Tool

**Purpose:** Penpot is an open-source design and prototyping platform built specifically for cross-domain collaboration between designers and developers. It solves the problem of proprietary vendor lock-in and handoff friction by using open web standards like SVG and generating ready-to-use CSS Grid and Flexbox layouts directly from the designs.

**Documentation:** https://help.penpot.app/

**Workflow Integration:** Designers build interactive prototypes in Penpot and share them with developers, who inspect the layouts and export clean CSS code directly into their frontend codebase.


### Tailwind CSS - CSS Framework

**Purpose:** Tailwind CSS is a utility-first CSS framework that lets developers build custom user interfaces rapidly by applying pre-built classes directly inside their HTML. It solves the problem of maintaining massive, tangled stylesheet files and ensures consistent spacing, colors, and responsive layouts across an entire project.

**Documentation:** https://tailwindcss.com/docs

**Workflow Integration:** Frontend developers combine Tailwind utility classes directly on HTML elements while building components, eliminating the need to constantly switch back and forth between HTML and CSS files.

### Playwright - Testing Framework

**Purpose:** Playwright is an open-source end-to-end testing framework created by Microsoft for automating and testing web applications across Chromium, Firefox, and WebKit browsers. It solves the problem of manual, repetitive QA testing by simulating real user interactions—like clicking buttons and filling out forms—to catch bugs before users see them.

**Documentation:** https://playwright.dev/docs/intro

**Workflow Integration:** Automated Playwright test scripts run automatically in the CI/CD pipeline whenever a developer submits new code, blocking broken updates from reaching production.
